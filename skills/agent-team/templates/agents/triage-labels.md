# Triage labels

The skills talk about five triage roles. This file maps each role to the string we use. Each one is a GitHub label on the issue. Role and wave labels are listed in [issue-tracker.md](issue-tracker.md).

| Role in mattpocock/skills | Our string        | Meaning                                 |
| ------------------------- | ----------------- | --------------------------------------- |
| `needs-triage`            | `needs-triage`    | The maintainer needs to look at it      |
| `needs-info`              | `needs-info`      | Waiting for more information            |
| `ready-for-agent`         | `ready-for-agent` | Fully specified, an agent can pick it up |
| `ready-for-human`         | `ready-for-human` | A human has to build it                 |
| `wontfix`                 | `wontfix`         | We won't do it                          |

To use other names, change the middle column.
